## 最近在做什么

我现在在南华早报（South China Morning Post）做 AI Agent Engineer，主要折腾搜索、推荐和 AI 系统。从内容如何被理解，到如何找到合适的信息，再到把它们变成真正能用的产品，都是我感兴趣的事情。

工作之外，也会做一些自己想用的小工具、读源码，顺手把遇到的问题修掉：

- [Tokdash](https://github.com/JingbiaoMei/Tokdash)：参与 AI 编程工具的用量统计和可视化，把日常使用变成看得见的数据。
- [开饭](https://github.com/674019130/kaifan)：一个本地优先、尽量减少重复的吃饭选择器，解决“今天吃什么”。
- [Claude Code 源码研究](https://github.com/674019130/learn-real-claude-code)：记录对 Agent 架构与实现的理解。
- [Yaak](https://yaak.app/)：贡献过 [IME 输入时的重命名修复](https://github.com/mountain-loop/yaak/pull/519)和[嵌套模板函数的深度跟踪修复](https://github.com/mountain-loop/yaak/pull/523)，两个改动都已合并。

依然喜欢代码规范、文档规范，也喜欢鼓捣花里胡哨的小东西。西瓜、夏天、冰块、诗、羽毛球和游戏，还是生活里很好的部分。想成为一个很会解决问题的人，也想一直写下去。

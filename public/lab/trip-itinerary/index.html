Trip itinerary

A trip plan as a stack of cards. Scroll, drag or use the arrow keys to walk the itinerary from the flight up to the cover photo.

Scroll or drag on the stack, click a card, or use ↑ ↓ on it.

Sample itinerary. The dates, places and prices are made up.

Key CSS & implementation tricks

// model.js: signed cyclic distance, (-3, 3]
export function offset(index, focus) {
  let d = (index - focus) % N;
  if (d > N / 2) d -= N;
  if (d <= -N / 2) d += N;
  return d;
}

// card j's top edge when focus is centred
const top0 = (appH - HEIGHTS[ORDER[focus]]) / 2;
if (d === 0) return top0;
if (d < 0)  return top0 - GAP - COLLAPSED - (-d - 1) * 70;
return top0 + HEIGHTS[ORDER[focus]] + GAP + (d - 1) * 70;
